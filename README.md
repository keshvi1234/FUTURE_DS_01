# Business Sales Performance Analytics

## Objective
Analyze business sales data and identify trends using Power BI.

## Tools Used
- Power BI
- Excel

## Dashboard Features
- KPI Cards
- Sales Trend Analysis
- Regional Sales Analysis
- Category Analysis
- Top 10 Products Analysis
- Interactive Filters/Slicers

## Key Insights
- West region generated the highest sales revenue.
- Technology category contributed the most sales.
- Sales showed strong growth in 2017.
- South region had comparatively lower sales.
- Consumer segment contributed significantly to orders.
